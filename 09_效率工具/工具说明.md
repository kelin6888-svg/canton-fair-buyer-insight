# 问卷回收统计工具 · 说明

> 调研执行阶段的效率工具：把「问卷回收份数统计」这类**高频、重复、易出错的手工填表工作**，变成「上传 → 预览核对 → 确认下载」三步。

---

## 一、它替代了哪段重复劳动

大型展会调研期间，各问卷平台会按时间段导出多份 Excel。执行人员每天/每期都需要把这些文件汇总进一张《调研问卷回收情况…》统计表：

1. 逐份打开问卷文件，数出有效记录条数；
2. 按**问卷类别**（统计表中的区块）和**回收日期**找到对应列；
3. 把数字填进对应单元格，再更新「总计」；
4. 反复核对编号范围有没有越界、重复、脏数据，日期有没有串行或漏列。

这段工作**每天重复、规则固定、但人工操作极易出错**：文件名与区块对不上、繁简写法不一致、日期列写错、编号越界未被发现，都会让统计表失真，且事后很难追溯是哪一步出的错。

本工具把第 1–4 步中**可规则化的部分交给确定性程序**，人只保留「预览核对」和「确认」两个判断动作。

### 带来的改变（定性，不做未经验证的量化承诺）

| 环节 | 手工方式 | 工具方式 |
|---|---|---|
| 文件归类 | 人工看文件名，逐份判断属于哪个区块 | 繁简统一后按文件名最长匹配自动归类；**匹配不到红牌拦截，要求手动指定，绝不静默兜底** |
| 列定位 | 人工找日期列、编号列 | 自动识别并展示「未找到时间列 / 编号列」「编号列可疑」等状态 |
| 数据核对 | 靠眼力逐格检查 | 自动列出脏/越界编号清单、模板缺失日期、各文件计入条数与将写入单元格 |
| 写入 | 手工改表，容易误改其他单元格 | 只覆盖问卷涉及的日期列，模板其他数据保持原样；**重复生成同一批数据结果不变** |
| 结果校验 | 人工复算总计 | 写入后输出「总计自检不一致单元格数」（0 为正常） |

工具界面文案中写明「可复用于下一期广交会」，即把一次性的手工劳动沉淀为**可复用的模板化流程**。

## 二、功能与操作步骤

1. **上传统计表模板**：读取模板结构（区块标题 / 期次 / 日期列 / 编号行），后续填表都按它来；可点「记住此模板」存到本机浏览器，下次免传。
2. **上传问卷**（可多选 / 拖拽）：一次上传多份 `.xlsx/.xls`，自动识别对应区块与时间/编号列；出现红色「未识别」时必须手动选对，未解决的文件不会进入生成。
3. **预览并生成**：先预览每份文件的区块、识别日期、计入统计条数、脏/越界编号、将写入单元格；核对无误后点「确认下载」，得到已填好「总计」的统计表。

## 三、可靠性设计（与主项目一脉相承）

这套工具与主系统采用同样的思路：**能用确定性规则算的，不交给人凭感觉判断；算完必须留可核对的依据**。

- **不静默兜底**：区块匹配失败直接拦截，避免「猜一个最接近的」造成错列。
- **先预览、后写入**：写入前完整展示每份文件的归类与计数，人工确认才落笔。
- **最小写入**：只改涉及日期列，模板其余内容原样保留；每次从原始字节重建 workbook。
- **幂等**：同一批数据重复生成，结果一致。
- **写入后自检**：输出总计不一致单元格数，异常可见。
- **防御性解析**：文件结构异常时返回空分析并由守卫跳过，不让程序崩溃。

## 四、数据安全

- **完全在本地浏览器运行**：问卷与统计表数据**不会上传到任何服务器**。
- 「记住此模板」使用浏览器 `localStorage`，数据仅保存在使用者本机。
- 随附 `xlsx.full.min.js`，与 HTML 放同一目录即可**完全离线使用**；若该文件缺失，工具会回退到 CDN 加载（仅加载库代码，不传输任何表格数据）。
- **仓库内只有工具代码，不含任何真实问卷、统计表或回收数据**；使用时需自行准备 Excel 文件。

## 六、边界与说明

- 本工具为**独立的小工具**，不是主系统模块，也不是企业级系统。
- 未做量化工时对比，因此**不声称具体提效百分比或节省人时**；上表为流程层面的定性对比。
