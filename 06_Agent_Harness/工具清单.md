# 工具清单

> 阶段 4 交付 · Harness 可调用的确定性工具（对应 analysis.py + data_loader.py）。

## 一、数据工具（data_loader.py）

| 工具 | 签名 | 说明 |
|---|---|---|
| 加载单问卷 | `load_questionnaire(code)` | 返回 (df, meta) |
| 质量检查 | `quality_check(df)` | 行数/列数/国家缺失/缺失率 |
| 加载全部 | `load_all()` | 返回 {code:{df,meta,quality}} + 概览表 |
| 字段定位 | `find_col(df, keywords)` | 按关键字定位列名 |

## 二、统计工具（analysis.py，均返回 (result, evidence)）

| 工具 | 签名 | 用途 |
|---|---|---|
| 大洲分布 | `continent_distribution(df, source)` | 国家→大洲标准化后计数 |
| 国家 Top | `top_countries(df, source, n)` | 国家出现频次 Top N |
| 单选分布 | `categorical_dist(df, source, keywords)` | 单变量频次（如采购额变化）|
| 多选计数 | `multi_select_counts(df, source, prefix)` | one-hot 多选题计数+占比 |
| 满意度汇总 | `satisfaction_summary(df, source, keywords)` | 档位分布 + 满意及以上占比 |

## 三、意图识别（qa.py）

| 意图 | 关键词 | 调用的工具 |
|---|---|---|
| 大洲分布 | 大洲/洲/地区分布 | continent_distribution |
| 国家分布 | 国家/排名/top | top_countries |
| 采购需求 | 采购需求/采购额/增长/下降 | categorical_dist(采购额变化) |
| 品类行业 | 品类/行业 | multi_select_counts(行业_) |
| 新兴产业 | 新兴/AI/电动车/锂电/光伏 | multi_select_counts(关注_) |
| 贸易服务 | 贸易/配对 | categorical_dist(配对需求) |
| 展商满意度 | 展商/参展商 | satisfaction_summary(参展商) |
| 参会满意度 | 参会/整体服务/满意度 | satisfaction_summary(整体服务) |
| 供应链因素 | 供应链/因素 | multi_select_counts(供应链因素_) |

## 四、工具约束

1. 所有统计工具**只读**，不改原始数据。
2. 每个工具返回 `evidence`（数据来源/字段/样本量/口径），供追溯。
3. 工具无匹配字段时返回空结果 + "字段缺失"，不抛异常、不编造。
