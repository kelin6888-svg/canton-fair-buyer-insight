# 工作流执行文档

> 阶段 4 交付 · 对应 `harness.py` 的 `Harness.run()`。

## 主流程（7 步）

```
用户提出分析任务
  ↓
① 识别问题类型（8 类：大洲/国家/采购需求/品类/新兴产业/贸易服务/展商满意度/参会满意度/供应链）
  ↓
② 确认可用问卷数据（映射到具体问卷 CSV）
  ↓
③ 检查字段和样本范围（字段定位 + 有效样本统计）
  ↓
④ 调用确定性统计工具（pandas 计算，返回结果+证据）
  ↓
⑤ 获取统计结果（含样本量/有效样本/口径）
  ↓
⑥ 检查证据与结论（无依据则判不合格，防幻觉）
  ↓
⑦ 质量评估 + 人工审核 + 生成报告 + 写执行日志
```

## 每步产物（可追溯）

| 步骤 | 产物 | 示例 |
|---|---|---|
| ① | 问题类型 | "大洲分布" |
| ② | 数据问卷 | demand（采购需求问卷）|
| ③ | 字段 + 样本 | 字段"国家"，样本 1409 |
| ④ | 工具名 | analysis.continent_distribution |
| ⑤ | 结果 | {Asia:707, Europe:232, ...} |
| ⑥ | 证据检查 | "有依据" / "无依据" |
| ⑦ | 质量评估 + 日志 | "通过" + JSONL 一条 |

## 执行日志格式（JSONL）

```json
{"任务": "哪些大洲采购商最多？", "问题类型": "大洲分布",
 "状态": "通过", "时间": "2026-11-15 01:37:00",
 "证据": {"数据来源": "采购需求问卷_清洗后.csv", "字段": "国家",
          "样本量": 1409, "有效样本": 1409, "统计口径": "有效样本内占比"}}
```

## 失败路径

- 意图无法识别 → 状态"无法识别问题类型"，明确拒答，不编造。
- 统计异常 → 状态"统计失败"。
- 样本为空 → 质量评估"不通过"。
