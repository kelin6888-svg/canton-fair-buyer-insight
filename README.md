# AI 国际采购商洞察与客户运营助手

**International Buyer Intelligence & CRM Copilot**

基于第 140 届广交会真实调研数据的 **AI 国际采购需求分析与市场洞察系统**。把 7 类问卷（清洗脱敏后约 5,700 条作答）转化为结构化数据资产、市场洞察与可追溯调研报告，并用单 Agent Harness 保证「AI 不编数字」。

> ℹ️ **公开仓库说明**：本仓库为作品集展示版，**不含逐条问卷数据** —— 7 份脱敏 CSV 与数据字典未随本仓库提供。数据仅保留在作者本地完整交付物中；如需复核，请通过 Issue 或直接与作者联系。源码运行需自行准备同结构数据，详见各文档。

## 运行产品

```bash
pip install -r 05_产品开发/requirements.txt
bash 05_产品开发/启动应用.sh
# 浏览器打开 http://127.0.0.1:8501
```

> ⚠️ 公开仓库不含 `03_数据工程/清洗数据/` 与 `真实脱敏数据/` 下的 CSV，直接运行会因缺少数据而失败。取得完整材料包后按相同目录结构放置 CSV 即可运行；仅查看界面请直接浏览 `08_求职作品集/产品截图/`。

应用共 5 个页面：数据概览 / 市场洞察 / AI 分析问答 / 执行与质控 / 自动报告。
技术栈：Python 3.13 · pandas · Streamlit 1.67 · Plotly。大模型 API 为可选（环境变量），默认纯规则问答，无外部依赖、无数据外传。

## 数据边界（重要）

- 唯一数据源：第 140 届广交会 7 份问卷导出数据，已脱敏（证件号 / IP / 来源详情 / 调研员编号全部剔除）。
- **公开仓库不含任何逐条问卷记录**；仅保留汇总统计、分析报告与清洗规则说明。
- **各问卷为独立样本**，作答记录数不可相加视为唯一采购商人数。
- **无访谈记录**：不做定性研究，不生成采购商原话。
- 无交易与跟进记录，因此不套用 RFM、不做真实 CRM 跟进；采购意向 ≠ 实际订单。
- 本系统为**独立个人项目原型**，不代表广交会官方系统，不暗示官方背书。

完整说明见 [`★数据来源与合规说明.md`](★数据来源与合规说明.md)。
