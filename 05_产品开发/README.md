# AI 国际采购商洞察与客户运营助手 · 应用运行说明

## 项目定位
基于第 140 届广交会真实调研数据的 **AI 国际采购需求分析与市场洞察系统**。
把 7 类问卷数据转化为结构化数据资产、市场洞察与可追溯调研报告。

> **v2 视觉版（当前）**：与《项目演示.pptx》统一的「科技蓝」设计体系。
> 主色 `#2563EB` · 辅色 `#06B6D4` · 强调色 `#F59E0B` · 浅色主题。
> 视觉只改呈现层（`app.py` + `theme.py` + `.streamlit/config.toml`），
> **7 个计算/数据模块一字未改**，所有统计口径与数值保持原样。

## 运行步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
# 视觉验收脚本额外需要（仅开发时用）：pip install playwright
```

### 2. 启动应用（三选一）
```bash
bash 启动应用.sh
# 或
cd 应用程序 && streamlit run app.py
```
浏览器打开 `http://127.0.0.1:8501`。

### 3. 核心测试（无需 UI）
```bash
cd 应用程序 && python test_core.py
```

### 4. 视觉验收（可选）
应用启动后另开终端：
```bash
cd 05_产品开发 && python capture_ui.py
```
会等待真实浏览器渲染完成，检查脚本异常，并把 5 个页面的截图输出到
`08_求职作品集/产品截图/`。

## 回滚到原版
```bash
cd 05_产品开发
mv 应用程序 应用程序_v2
cp -r 应用程序_原版备份_20261115 应用程序
# 重启应用即可
```
原版为未做任何视觉改动的 v1，业务逻辑与 v2 完全相同。

## 功能说明（P0 已实现）

| 页面 | 功能 |
|---|---|
| 01 数据概览 | 7 份问卷质量审查（行数/列数/缺失率）+ 脱敏与质量限制说明 |
| 02 市场洞察 | 大洲/国家分布、品类、新兴产业、满意度（渐变交互图表 + 逐图来源脚注）|
| 03 AI 分析问答 | 8 类问题 + 示例快捷提问，八段式回答带证据与 Harness 执行轨迹 |
| 04 执行与质控 | Harness 执行日志、通过率统计、可追溯明细 |
| 05 自动报告 | 一键生成可追溯 Markdown 报告 + 下载 |

## 关键设计

- **确定性优先**：AI 问答只调用 pandas 统计结果，不依赖模型记忆编造数据。
- **证据可追溯**：每个回答带数据来源、字段、样本量、统计口径；每张图带来源脚注。
- **质量控制**：Harness 工作流 = 识别类型 → 确认数据 → 字段/样本检查 → 确定性统计 → 证据/结论检查 → 质量评估 → 执行日志。
- **数据安全**：敏感字段已在清洗阶段剔除；原始数据只读；无授权资料不上传外部 API。
- **视觉与作品集统一**：配色取自 PPT 设计规范；顶部 Hero、KPI 卡、胶囊 Tab、渐变图表、口径提示均为 `theme.py` 设计系统组件。

## 数据来源与红线

- 唯一数据来源：第 140 届广交会 7 份问卷（已脱敏）。
- 无访谈记录，不做定性研究；不虚构采购商原话。
- 采购意向 ≠ 实际订单；各问卷为独立样本，样本量不可相加。
- 本系统为独立个人项目原型，不代表广交会官方系统。
