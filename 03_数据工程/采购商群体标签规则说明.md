# 采购商群体标签规则说明

> 阶段 2 交付 · 基于第 140 届问卷真实字段，定义可计算、可追溯的群体标签。不使用交易金额/购买频次等不存在的数据，不套用传统 RFM。

## 一、标签设计原则

1. **只基于真实存在的字段**，不虚构交易/跟进数据。
2. 每个标签可追溯到具体问卷字段与样本口径。
3. 标签用于"群体画像与对比"，非"个体客户运营"（无跟进记录，不做 CRM）。

## 二、标签维度（真实字段支撑）

| 维度 | 来源字段 | 示例标签 |
|---|---|---|
| 地域 | 国家/地区、市场 | 亚洲/欧洲/南亚/拉美… |
| 品类 | 行业(14类)、新兴产业(6类)、展区 | 电子家电/工业制造/AI/绿电… |
| 采购需求 | 需求变化、采购额变化、未来预期 | 需求旺盛、采购额增长、扩大采购 |
| 供应链考量 | 供应链因素(9项) | 价格敏感、品质导向、研发创新导向 |
| 服务需求 | 贸易配对、配套服务、住宿/餐饮 | 需配对服务、需物流/检测/金融 |
| 满意度 | 展商/展品/参会服务评分 | 高满意度、待改进 |

## 三、标签定义与计算方式

### 1. 需求强度标签（基于采购需求问卷）
- **高需求增长**：采购额变化 = 增长（任一档）。
- **需求乐观**：未来 6 个月预期 = 乐观/旺盛。
- **扩量采购**：未来 1–3 年规划 = 扩大采购规模。
- 计算：按字段值分组计数，占比 = 该组 / 有效样本。

### 2. 品类偏好标签（基于行业/新兴产业/展区）
- 按多选题各选项计数，输出品类热度排名与占比。

### 3. 供应链考量标签（基于供应链因素多选题）
- 价格导向 / 品质导向 / 交付导向 / 研发创新导向 / 稳定导向等，按选项计数。

### 4. 市场标签（基于市场字段）
- 欧盟 / 美国 / 东南亚 / 日韩 / 中东 / 俄罗斯及中亚 / 欧洲(非欧盟) / 拉美 / 非洲 / 大洋洲 / 其他。

### 5. 服务需求标签（基于贸易服务/住宿/餐饮问卷）
- 需配对服务、需配套服务商类型、住宿价格敏感、餐饮偏好等。

## 四、群体画像输出

对任一群体（如"亚洲采购商"）输出结构化画像：
- 地域分布、品类偏好 Top、需求强度、供应链考量、服务需求、满意度。

## 五、适用条件与不适用场景

- **适用**：群体层面的分布、对比、洞察（本产品核心）。
- **不适用**：个体客户跟进、客户流失识别、成交预测（无交易/跟进数据，明确不做）。

## 六、阈值与口径

- 所有占比以"有效样本"为分母，缺失值不计入。
- 多选题占比 = 选择该项的样本数 / 有效样本数（可能 >100%，因可多选）。
- 不设主观阈值，避免伪精确；仅输出可追溯的计数与占比。
