# 数据处理脚本说明

本目录仅保留 2 个核心脚本的**路径脱敏版**，用于说明清洗与数据字典的生成逻辑。

- 原始问卷导出文件（含证件号 / IP 等敏感字段）与内部调研方案**不在材料包内**，
  因此脚本中的原始资料路径已替换为占位符 `<原始资料目录>`、项目路径替换为 `<项目根目录>`。
- 这些脚本在材料包内**仅供阅读**，不可直接对原始资料重跑；如需复现，请自行准备
  对应的原始导出文件并把占位符替换为实际路径。
- 完整的清洗规则、去重数量、缺失率与已知质量问题，见
  `../数据质量审查报告.md`；字段口径见 `../数据字典/数据字典_140届7问卷_完整版.xlsx`。
- 公开仓库版不含清洗后成果数据；取得完整材料包后，可用 `05_产品开发/应用程序/test_core.py`
  或 `07_测试与评估/test_suite.py` 复核数字。
