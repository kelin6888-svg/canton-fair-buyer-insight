# 国际采购需求分析报告（v1）

> 阶段 2 交付 · 基于第 140 届广交会 7 份问卷清洗后数据。所有数字可追溯到对应 CSV 文件与字段。

| 分析维度 | 数据来源 | 样本量 |
|---|---|---|
| 采购需求变化 | 采购需求问卷_清洗后.csv | 1409 |
| 新兴产业需求 | 新兴产业问卷_清洗后.csv | 607 |

> 口径说明：各问卷为独立样本，不跨问卷相加；百分比为该问卷有效样本内占比。

## 二、国家/地区分布

以参会服务问卷（814 条，国家完整）为代表：

| 大洲 | 占比 |
|---|---|
| 亚洲 | 约 50% |
| 欧洲 | 约 15% |
| 北美 | 约 10% |
| 非洲 | 约 10% |
| 南美 | 约 9% |
| 大洋洲 | 约 4% |

其余问卷分布一致：**亚洲采购商占比最高（约五成），欧洲次之**，符合广交会境外采购商结构。

## 三、采购需求变化（核心）

基于 1409 条采购需求问卷（数字复用旧项目独立核验结果）：
- **79.3% 采购商预计今年对华采购额增长**，仅 5.2% 预计下降（净增长 +74.2 个百分点）。
- 77% 对未来 6 个月产品市场需求持乐观预期。
- 50.8% 未来 1–3 年计划扩大对华采购规模。
- 市场差异：所有市场净增长为正，南亚、拉美相对最强。

## 四、商品品类

- 采购需求问卷行业（14 类）以电子家电、工业制造等为主（复用旧项目结论）。
- 新兴产业问卷：AI（31.8%）最受关注，绿电装备（23.1%）、电动汽车（22.1%）次之；"技术"（35.1%）首次与"成本性价比"（33.9%）并列成为首要供应商考量。

## 五、贸易服务需求

基于 645 条贸易服务问卷：
- **88.1% 采购商（568/645）需要广交会提供贸易配对服务**。
- 采购商愿意提交采购品类、数量、金额、规格等需求信息以提升配对精准度。

## 六、展商展品评价

基于 623 条展商展品问卷：
- 参展商整体满意度：满意及以上约 91.4%（非常满意 47.7% + 满意 43.7%）。
- 展品整体满意度：满意及以上约 90.4%。
- 采用重要性-绩效分析（IPA）对标供应商能力与产品属性的"期望重要性 vs 参展实际感受"（详见阶段 3 Dashboard 交互分析）。

## 七、参会服务评价

基于 814 条参会服务问卷：
- 对第 140 届广交会整体服务满意度：满意及以上约 92.5%（非常满意 59.3% + 满意 33.2%）。

## 八、结论

1. 境外采购商对华采购需求**整体景气**（近八成预计采购额增长），新兴战略产业（AI/绿电/EV）是结构亮点。
2. 采购商对广交会展商、展品、参会服务满意度**普遍较高（约九成满意及以上）**。
3. 贸易配对服务是明确的**增量需求**（近九成需要），是运营与决策的抓手。

## 九、结论限制（必须声明）

1. 采购意向 ≠ 实际订单；问卷为到会采购商截面样本，非全量出口市场。
2. 无访谈记录，本报告不含定性分析，全部为结构化问卷统计。
3. 满意度编码方向依据问卷选项顺序推断，以数据字典为准。
4. 餐饮/住宿样本存在字段缺失，未纳入本报告核心结论。
