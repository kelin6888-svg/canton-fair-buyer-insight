# 竞品分析

> 阶段 1 交付 · 基于 2026 年公开资料（官网/行业横评），标注来源与检索日期。仅作产品定位参考，不编造功能与价格。

## 一、竞品全景（三类相关产品）

本产品的差异化不是做通用 CRM 或通用 BI，而是**面向展会/贸易调研场景的垂直"AI 调研分析 + 质量追溯"工具**。相关竞品分三类：

### 1. B2B CRM（客户管理）
| 产品 | 定位 | 与本项目的关系 |
|---|---|---|
| 纷享销客 Agentic CRM | 营销服一体化 + 自研 AgentOS(ShareHive)，自然语言问数、AI 归因、主动预警 | 场景不同（销售管理 vs 调研分析），但其"Agent + Skill + 语义层"思路可借鉴 |
| 销售易 | 中高端 B2B 复杂销售 | 场景不同 |
| 小满 OKKI | 外贸 B2B 专属（海外客户/邮件/海关数据）| 外贸场景相近，但偏销售履约 |
| 探迹智能销售云 | 企业大数据 + AI 拓客 | 偏获客，非调研分析 |
| Salesforce / HubSpot / Zoho | 国际通用 CRM | 通用，非调研场景 |

### 2. 智能商业分析 BI
| 产品 | 关键能力 | 借鉴点 |
|---|---|---|
| 帆软 FineBI（AI 原生）| 指标中心 + 语义层 + **确定性计算引擎（NL2DSL→BI语义层→计算）** + **三级溯源** | 核心借鉴：AI 不裸查表，先对齐指标/维度，再确定性计算，结论可溯源 |
| 观远数据 | AI+BI 易用性，零售消费深耕 | 场景化分析思路 |
| 思迈特 Smartbi | AI 问数 + 私有化 + 信创 | 合规/权限思路 |
| Power BI + Copilot / Tableau | 国际 BI 巨头 AI 演进 | 通用 |

### 3. AI 数据分析问答（ChatBI / Data Agent）
- 共同趋势：**从"AI 直查 SQL"转向"语义层 + 确定性计算 + 溯源校验"**，防止大模型编造数据。
- 代表：FineBI 分析 Agent、Smartbi AIChat、观远问数、阿里 Quick BI、ThinkingAI。

## 三、差异化结论

1. 通用 CRM/BI 都**不做"展会多类问卷"的字段映射与样本口径管理**，这正是本项目的空白点。
2. 行业趋势（FineBI 确定性计算引擎、三级溯源）印证了本项目 Harness"确定性统计 + 证据引用 + 幻觉识别 + 人工审核"的设计合理性——这不是拍脑袋，而是行业共识。
3. 本项目不做销售/履约/预测，**专注"把分散问卷变数据资产 + 可追溯洞察报告"**，范围可控、可验证。
