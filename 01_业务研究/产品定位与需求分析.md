# 产品定位与需求分析

> 阶段 1 交付 · 范围修正后。

## 一、一句话定位

**基于第 140 届广交会真实调研数据，把分散的 7 类问卷转化为结构化数据资产、市场洞察和可追溯调研报告的 AI 国际采购需求分析系统。**

## 二、目标用户（主次）

- **主用户**：展会/贸易促进机构的调研分析人员（对应调研问卷场景）。
- **次用户**：企业外贸分析人员、市场研究运营人员。

## 三、解决的核心问题

1. 7 类问卷格式不同、字段各异、分时段导出难合并 → 统一字段映射 + 清洗 + 字典。
2. 不同国家/地区/品类需求难比较 → 结构化洞察 + 可视化对比。
3. AI 分析易出错、无依据 → 确定性计算 + 证据引用 + 口径追溯 + 人工审核。
4. 写报告耗时 → 自动生成可追溯报告。

## 四、核心价值主张

- **数据资产化**：7 类问卷 → 统一数据字典 + 字段映射 + 清洗后数据集。
- **洞察结构化**：国家分布 / 采购需求 / 品类 / 贸易服务 / 展商展品 / 参会服务。
- **结果可信**：每个数字可追溯到文件、字段、样本量、统计口径。
- **效率**：AI 问答 + 自动报告，减少手工汇总。

## 五、业务闭环

```
7类问卷脱敏数据 → 字段映射/清洗 → 描述统计/交叉分析 → 群体画像/对比
→ AI问答(带依据) → 自动报告 → 质量审核(口径/幻觉/人工) → 追溯
```

## 六、差异化（相对竞品）

| 竞品 | 本项目差异 |
|---|---|
| 通用 CRM（纷享销客/销售易/Salesforce）| 不做销售/履约，专注调研分析 |
| 通用 BI（FineBI/观远/PowerBI）| 垂直展会问卷场景，内置字段映射与样本口径 |
| ChatBI（Smartbi/ThoughtSpot）| 强调问卷样本口径、幻觉识别、人工审核闭环 |

## 七、MVP 范围（L2 最低目标）

导入 7 类脱敏问卷 → 质量审查 → 洞察 Dashboard → 群体画像 → AI 问答（带依据）→ 自动报告 → 口径追溯。

## 八、限制与边界

- 仅结构化问卷分析；无访谈记录，不做定性研究。
- 采购意向 ≠ 实际订单；问卷为到会采购商截面样本。
- 不暗示官方背书；真实敏感信息脱敏剔除。
