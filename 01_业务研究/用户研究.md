# 用户研究（范围修正 v2）

> 阶段 1 交付 · 聚焦调研/分析人员，弱化销售运营，取消 CRM 定位。

## 一、三类目标用户画像

### 用户 A：展会/贸易促进机构调研人员（主用户）
- **角色**：负责采购商问卷调研、数据统计、报告撰写。
- **任务**：组织回收、清洗数据、出统计与专报。
- **痛点**：问卷多、格式杂、分时段导出难合并；缺统一数据字典；统计靠手工 Excel；AI 结论无依据难复核。
- **数据需求**：分市场/品类的需求分布、采购额变化、服务评价、可追溯口径。
- **场景**：每日回收后快速汇总，向主管汇报阶段结论。

### 用户 B：企业国际业务 / 外贸分析人员
- **角色**：了解海外市场需求、识别重点市场与品类机会。
- **任务**：分析国家/品类需求差异、判断哪些市场值得投入。
- **痛点**：缺乏统一的需求画像，难快速比较不同市场。
- **数据需求**：国家/品类需求对比、需求强度、贸易服务需求。
- **场景**：展会结束后复盘采购需求趋势，制定市场策略。

### 用户 C：市场研究 / 运营分析人员
- **角色**：出洞察、做决策支持、验证 AI 结论。
- **任务**：群体标签、对比分析、AI 问答核验、报告输出。
- **痛点**：AI 结论缺依据、口径不清、难以复核。
- **数据需求**：群体标签、AI 问答带依据、样本量与口径、执行留痕。
- **场景**：用 AI 快速生成分析并逐项核验数据来源。

## 三、用户旅程地图

**调研/分析人员主线**：
```
接到任务 → 检查数据(格式/缺失/重复/批次) → 建立字典 → 清洗合并(区分时段)
→ 生成洞察(分布/交叉) → 群体画像/对比 → AI 提问核验 → 撰写报告 → 复核口径 → 提交
情绪：焦虑(数据乱) → 逐步清晰(可核查) → 安心(有依据) → 有成就感(能交付)
```
