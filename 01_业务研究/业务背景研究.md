# 业务背景研究（范围修正 v2）

> 阶段 1 交付 · 依据《第140届境外采购商调研方案》与 7 份问卷真实字段整理。仅使用第 140 届广交会资料。

## 一、广交会的业务定位

中国进出口商品交易会（广交会，Canton Fair）是中国对外贸易的重要平台，第 140 届于 2026 年 10 月 15 日—11 月 4 日在广州举办。

官方调研方案对广交会的定位是发挥三大作用：**“晴雨表”“风向标”“推进器”**——即通过境外采购商的到会与采购行为，反映国际贸易景气、指引产业方向、推动外贸高质量发展。

## 二、第 140 届调研方案核心（业务事实）

**调研目的**：研判重点市场采购商采购需求变化与趋势，优化展商展品结构，提升商旅与贸易服务水平，为“三位一体”大招商体系（多渠道精准招商、全链条优化服务、数智化高效赋能）提供决策参考。

**三大调研主题**：
1. **重点市场需求**：欧盟、美国等重点市场采购需求、采购额变化、供应链布局调整；贸易壁垒、地缘政治对采购决策的影响。
2. **展商展品综合竞争力**：重要性—绩效分析（IPA），对标采购商对供应商能力/产品属性的“期望重要性”与“参展实际感受”。
3. **全旅程参会 + 全链条贸易服务**：展前办证邀约、场馆服务、餐饮住宿、支付交通；会员服务。

**调研方式与规模（目标）**：问卷调研预计回收 8000 份；访谈调研预计 200 份（广交贵客/尊客）。

> 说明：本人**无访谈记录**，本项目只基于问卷数据做结构化分析，不涉及访谈定性研究。

**7 份问卷**：重点市场采购需求变化、境外采购商综合（新兴战略产业）、展商展品评价、全旅程参会服务、贸易服务、住宿、餐饮。

## 三、采购商全旅程业务流程

```
①获取信息 → ②办证邀约(邀请函) → ③到会观展 → ④寻找供应商/产品
→ ⑤表达采购需求 → ⑥使用贸易服务(展前/展中/展后) → ⑦商务沟通/成交 → ⑧后续跟进/复购
```

每一环都产生数据，但分散在不同问卷中——这正是产品“数据获取→处理→洞察→画像→报告”闭环的业务起点。

## 四、调研业务流程（产品要复刻的主干）

```
问卷设计 → 现场/线上发放 → 分时段回收导出 → 数据清洗核查
→ 统计分析(分布/交叉) → 采购需求洞察 → 展商展品竞争力(IPA) → 服务短板识别
→ 撰写专报 → 决策建议
```

关键业务事实：
- 问卷按时间段分批导出，存在**阶段性累计快照 vs 独立时段**的区分问题。
- 不同问卷由不同受访者填写，样本量不同、口径不同，**不能简单相加**。
- 住宿/餐饮问卷列数跨批次有变化（问卷设计演进），合并前须字段对齐。

## 五、业务痛点（产品价值来源）

1. 多类问卷格式不同、字段各异，人工整理效率低。
2. 不同国家/地区采购需求难快速比较。
3. 大量采购商信息难形成统一画像与标签。
4. 采购需求与服务痛点难及时转化为洞察结论。
5. 研究/分析人员查找资料、汇总数据、写报告耗时。
6. AI 直接生成分析易出现数据错误、来源不明、结论无证据。

## 六、对产品的业务启示

1. 功能划分应贴合三大调研主题 + 服务维度，而非凭空造功能。
2. 分时段快照问题决定数据层必须“先审计再合并”。
3. 多问卷独立样本决定分析必须标注口径、不跨问卷虚构唯一客户。
4. AI 层必须实现“可追溯、可复核、防幻觉”的可靠性机制（呼应 Harness 的质量控制定位）。
