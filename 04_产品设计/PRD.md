# PRD · AI 国际采购商洞察与客户运营助手

> 版本 v2.0（范围修正后）· 2026-11-15

## 1. 产品定位

一套**基于第 140 届广交会真实调研数据的 AI 国际采购需求分析与市场洞察系统**。

**核心价值**：帮助研究人员把分散的多类问卷数据，转化为结构化的数据资产、市场洞察和可追溯的调研报告，并利用 AI 工作流提高分析效率与结果可靠性。

> 明确边界：本产品为独立个人项目原型，不代表广交会官方系统；不使用官方 Logo，不暗示官方背书。

## 2. 唯一数据来源

第 140 届广交会资料：调研方案、中英文问卷、问卷回收统计、7 类问卷导出数据、调研执行管理资料。

**不使用**：与本项目无关的个人实习经历、其他个人项目数据及背景资料。

## 3. 用户画像

| 角色 | 任务 | 痛点 | 数据需求 |
|---|---|---|---|
| 展会/贸易促进机构调研人员（主） | 组织回收、清洗、统计、写专报 | 问卷多格式杂、分时段难合并、统计靠手工 | 分市场/品类需求、服务评价、可追溯口径 |
| 企业国际业务/外贸人员 | 了解海外需求、找市场机会 | 缺统一画像、难判断重点市场 | 国家/品类需求对比、需求强度 |
| 市场研究/运营分析人员 | 出洞察、做决策支持 | AI 结论无依据难复核 | 分层标签、AI 问答带依据 |

## 4. 核心需求与功能（按 P0/P1/P2）

### P0（必须完成）
1. 多类问卷数据导入（7 类问卷 xlsx）
2. 数据清洗与质量审查（缺失/重复/异常/字段对齐）
3. 问卷字段映射（中英/繁简、多选展开、统一字典）
4. 国家和地区分布分析
5. 采购需求分析（需求变化、采购额变化、未来预期）
6. 商品品类分析（行业 14 类 / 展区 / 六大新兴产业）
7. 贸易服务需求分析
8. 展商展品评价分析（IPA 重要性-绩效）
9. 参会服务评价分析
10. 数据可视化（交互图表）
11. AI 数据分析问答（调真实计算结果）
12. 自动生成调研分析报告
13. 数据来源与计算口径追溯

### P1（数据支持时开发）
1. 采购商群体画像（国家+品类+需求+服务，结构化字段聚合）
2. 不同国家和地区需求对比
3. 不同服务项目的评价差异
4. 多届历史数据比较（谨慎，口径需对齐）
5. ~~采购商类型差异~~ → **D（缺"采购商类型"字段）**

### P2（重新设计）
- **取消真实 CRM 客户跟进系统**（无访谈/跟进/订单数据）。
- 保留轻量"采购商群体标签 / 分析结果管理"功能，不作为真实 CRM 展示。
- 若为演示交互使用模拟数据，必须**单独标注**，不与真实数据混合。

## 5. 功能结构

```
数据层：7 类问卷脱敏数据 + 数据字典 + 字段映射
  ↓
分析层：清洗 → 描述统计 → 交叉分析 → 画像 → 对比 → IPA
  ↓
AI 层：数据分析问答（确定性计算 + 依据引用 + 口径检查）
  ↓
Harness 层：任务拆解 → 工具调用 → 证据 → 质检 → 人工审核 → 执行日志
  ↓
输出层：可视化 Dashboard + 自动报告 + 群体标签管理
```

## 6. 用户流程

```
导入问卷 → 质量审查 → 字段映射 → 查看洞察(分布/需求/品类/服务)
→ 群体画像/对比 → AI 提问(带依据) → 生成报告 → 审核与追溯
```

## 7. 业务规则

1. 分时段批次先审计（是否累计快照），确认后再合并；无法确认则独立分析并注明。
2. 不同问卷样本独立，不跨问卷虚构唯一客户，不把样本量直接相加。
3. 敏感字段（证件号/IP/来源详情/调研员编号）一律剔除。
4. 开放文本字段若分析，必须标注"来源=问卷开放题"，不得描述为访谈。
5. AI 回答格式：问题说明 → 统计范围 → 样本量 → 数据来源 → 发现 → 解释 → 建议 → 结论限制。

## 8. 异常情况处理

- 字段缺失/列数跨批次不一致 → 字段对齐 + 缺失统计 + 标注。
- 多选题 0/1 编码 → 统一为 1/0 或 1/NaN，口径一致。
- 数据量过小（如展商展品 103 条）→ 标注样本量，结论加限制说明。
- AI 无数据支撑 → 明确回答"该问题无对应数据"，不编造。

## 9. MVP 范围（L2 最低目标）

导入 7 类脱敏问卷 → 质量检查 → 洞察 Dashboard → 群体画像 → AI 问答（带依据）→ 报告导出 → 口径追溯。

## 10. 技术方案

Streamlit + pandas + SQLite + Plotly + 本地规则工具 + 可选大模型 API（Key 放环境变量）。
